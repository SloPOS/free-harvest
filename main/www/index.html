Free Harvest
version 0.1
Open-source monitoring and configuration for Harvest Right freeze dryers, running entirely on an ESP32-S3. Works standalone (this web app) or as an MQTT device for Home Assistant.

Quote this version number when reporting an issue.

–
Project on GitHub Report an issue
These open github.com, so they need internet on the device you are browsing from — the adapter itself never reaches the internet.

Batch

Sent to the dryer as SETBNAME. Naming a batch does not start it.

Wi-Fi

The setup hotspot only stays open for 5 minutes after a failed connection, then shuts off until the adapter is rebooted.

Home Assistant / MQTT

Point this at your Mosquitto broker (often the Home Assistant machine's IP). The dryer then appears in HA automatically via MQTT discovery. If it won't connect, open Debug & advanced → Device log — the exact error is logged there.

Firmware update

Writes to the spare slot and verifies before switching. A bad file is rejected and the current firmware keeps running.

USB link to dryer

enumerated —
connect events —
bytes received —
USB-level counters, measured before any protocol decoding. They separate "the dryer never connected" from "it connected but sends nothing" from "it sends bytes we fail to parse" — three faults that look identical on the dashboard.

Device log

(tap Refresh)
Live log from the adapter — the first place to look when Wi-Fi or MQTT won't connect.

Clock

Sends SETDATE with your browser's current date/time.

Raw command

Only commands that read data or beep are offered. Hardware-control verbs (duty cycle, heater/pump, reboot) are blocked in firmware and cannot be sent from this app.

Logbook

Control PIN

Required for anything that changes the dryer. Monitoring stays open to everyone on the network. This keeps a housemate or a guest from tapping Start — it is not a login, and it does not make the adapter secure against someone who is actually trying.

There is no recovery. Forgetting the PIN means reflashing to clear it.

Recipes

Saved on the adapter, so they survive a reboot and are the same on every device. Sending a recipe with Start begins a batch immediately - it needs Remote control switched on, and it asks first.

Remote control

Off by default. With this on, the dashboard shows the buttons the dryer is currently offering and can press them. Anything that starts, ends or skips part of a cycle asks first. Monitoring works either way, so leave it off unless you want the adapter able to drive the machine.
