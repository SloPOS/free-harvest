Free Harvest
version 0.1
Open-source monitoring and configuration for Harvest Right freeze dryers, running entirely on an ESP32-S3. Works standalone (this web app) or as an MQTT device for Home Assistant.

Quote this version number when reporting an issue.

–
Project on GitHub Report an issue
These open github.com, so they need internet on the device you are browsing from — the adapter itself never reaches the internet.

Batch

Sent to the dryer as SETBNAME. Naming a batch does not start it.

Wi-Fi

The setup hotspot only stays open for 5 minutes after a failed connection, then shuts off until the adapter is rebooted.

Home Assistant / MQTT

Point this at your Mosquitto broker (often the Home Assistant machine's IP). The dryer then appears in HA automatically via MQTT discovery. If it won't connect, open Debug & advanced → Device log — the exact error is logged there.

checking …
The dryer keeps a CSV log of every batch it runs, a row a minute, with the shelf and ambient thermocouples, the vacuum and the phase — history from before this adapter existed, and the ambient reading no live frame carries. Reading one asks the dryer for it a kilobyte at a time; nothing is stored on the adapter.

enumerated —

USB-level counters, measured before any protocol
        decoding. They separate "the dryer never connected" from "it connected
        but sends nothing" from "it sends bytes we fail to parse" — three faults
        that look identical on the dashboard.

    


    

      
Dryer firmware

      
build —

      
      

      
A dryer on build 6.0.644170 answers the identity query
        once and then sends no telemetry. Switching this on makes the adapter
        introduce itself the way the genuine one does — UNIQUE lH,
        and re-asking for the name, configuration and a status frame every
        15 s until answered. Harmless on 6.0.641041. Takes effect at once and
        is remembered.

Reboot the dryer

      
      

      
Ends any batch in progress. A restarted machine
        does not resume a run — whatever was inside is lost. Use it when the
        panel has locked up and there is nothing left to lose.

      
Unverified. This sends
        the dryer's REBOOT command, which has never
        been tested on a real machine. It is on this project's never-probe list
        precisely because a verb's name is not evidence of what it does —
        SPC reads like a pump control and sets the
        display colour; ADV was recorded as dead and
        starts cycles. Treat the outcome as unknown.

    


    

      
Raw command

      

        
        
      

      

        
        
      

      
      

      
Only commands that read data or beep are offered.
        Hardware-control verbs (duty cycle, heater/pump, reboot) are blocked in
        firmware and cannot be sent from this app.

Control PIN

      

      

        
        
      

      

        
        
      

      

        Required for anything that changes the dryer. Monitoring stays open to
        everyone on the network. This keeps a housemate or a guest from tapping
        Start — it is not a login, and it does not make the adapter secure
        against someone who is actually trying.
        


        There is no recovery. Forgetting the PIN means reflashing to
        clear it.

Remote control

      

        
        
      

      

        Off by default. With this on, the dashboard shows the buttons the dryer
        is currently offering and can press them. Anything that starts, ends or
        skips part of a cycle asks first. Monitoring works either way, so leave
        it off unless you want the adapter able to drive the machine.
